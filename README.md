# RipAdbaisor - Ranking de restaurantes

## Objetivo
Aplicación Java con Swing que permite gestionar un ranking de restaurantes.

## Funcionalidades
- Añadir restaurante
- Editar restaurante
- Mostrar restaurantes ordenados por puntuación
- Eliminar restaurante
- Salir del programa

## Tecnologías
- Java
- Swing
- Git y GitHub

## Manual de uso
1. Ejecuta el programa.
2. Selecciona una opción del menú.
3. Introduce los datos solicitados.
4. Usa la opción 5 para salir.
